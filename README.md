# toeic-lc-repeater

토익 LC 음원에서 짧은 문장 하나를 골라 정한 횟수만큼 반복해 듣는 학습 도구.

## 하려는 것

1. mp3를 넣으면 음성 인식(Whisper)으로 영어 문장과 시작·끝 시간을 뽑는다.
2. 문장 목록을 `claude -p`로 한 번에 번역해 한국어를 붙인다.
3. 재생 화면에서 문장 하나를 N회 반복하고, 탭하면 영어 ↔ 한국어가 바뀐다. 다음을 누르면 다음 문장으로 간다.

## 진행 순서

- 1단계: 맥에서 처리하는 스크립트 + 로컬 웹 플레이어로 문장 경계 품질과 반복 사용감 확인
- 2단계: 필요하면 같은 결과물(JSON + mp3)을 읽는 아이폰 플레이어

## 주의

교재 음원과 스크립트는 저작권물이라 저장소에 올리지 않는다. 음원과 처리 결과는 `.gitignore`로 제외한다.
