# toeic-lc-repeater

토익 LC 음원에서 짧은 문장 하나를 골라 정한 횟수만큼 반복해 듣는 학습 도구.

mp3를 올리면 문장 단위로 잘라 주고, 문장마다 한국어 번역을 붙인다. 음원 언어는 **영어**와 **일본어**(JLPT 청해 등) 중에서 올릴 때 고른다. PC와 아이폰 모두 카드는 원문(영어·일본어)이 흐릿하게 가려진 상태로 시작한다. 누를 때마다 원문 공개 → 한국어 → 다시 원문 가리기 순서로 바뀌며, 다른 문장으로 이동하면 다시 가려진다.

## 아이폰 앱으로 쓰기

SwiftUI 앱은 시작 화면에서 **컴퓨터에서 불러오기 / 기기에서 시작하기**를 선택한다.

- **컴퓨터에서 불러오기**(iOS 17+): 기존 PC 레슨을 가져와 오프라인으로 반복 재생한다.
- **기기에서 시작하기**(iOS 26+·지원 기기): 음원 언어(영어/일본어)를 고르고 음원을 선택하면 애플의 기기 내 모델로 전사·한국어 번역하여 레슨을 만든다. Apple Intelligence는 사용하지 않는다. [기기 처리 안내](docs/ios-local-processing.md)

레슨 파일 확장자는 `.lrlesson`(Listen & Repeat)이다. 예전 이름인 `.lcrlesson` 파일도 그대로 가져올 수 있다.

레슨은 **폴더**로 나눠 관리할 수 있다. 아이폰은 보관함 오른쪽 위 폴더 메뉴에서 폴더를 고르거나 만들고, 레슨을 길게 눌러 **폴더로 이동**한다. **기기에서 시작하기**에서는 음원을 여러 개 골라 차례로 처리하고 저장할 폴더를 고를 수 있다.

PC에서 가져오는 경로는 다음과 같다.

1. PC 앱/웹 플레이어의 **아이폰용 레슨 내보내기**로 `.lrlesson` 파일을 저장한다.
2. AirDrop이나 iCloud Drive로 옮기고 아이폰 앱의 **가져오기**에서 연다.
3. 앱 IPA는 `bash scripts/build_ios.sh` 또는 GitHub Actions로 빌드하고 Feather에서 직접 서명·설치한다.

PC 처리와 아이폰 학습은 분리되어 있어, 가져온 뒤 PC를 켜 두거나 서버에 접속할 필요가 없다.
빌드·Feather 설치·전달 형식·검증 범위는 [아이폰 앱 안내](docs/ios-transfer.md)에 정리했다.

## 윈도우 앱으로 쓰기

Windows 10/11 64비트에서 `LC-Repeater-Setup-x64.exe`를 실행한다.
FFmpeg·whisper-cli는 포함되어 있고, WebView2가 없으면 설치 중 준비한다.
첫 실행 때 모델을 내려받으며, 데이터는 `%LOCALAPPDATA%\LC Repeater\`에 저장된다.
설치·번역 준비·빌드·검증 범위는 [Windows 앱 안내](docs/windows.md)를 참고한다.

## 네이티브 맥 앱으로 쓰기 (macOS 26+, Apple Silicon)

SwiftUI로 만든 맥 앱이다. 새 레슨을 만들 때 전사와 번역 방식을 각각 고른다.

| | Apple 기기 내 처리 | 기존 방식 |
|---|---|---|
| 전사 | Apple 음성 인식(`SpeechAnalyzer`) | Whisper (whisper.cpp, 모델 547MB) |
| 번역 | Apple 번역(`Translation`) | Claude (`claude -p`) |

- 영어·일본어 음원 여러 개를 창에 끌어다 놓거나 **새 레슨 만들기**(⌘N)에서 한꺼번에 골라 차례로 처리한다. 파일마다 진행 상황이 보이고, 실패한 파일만 다시 하거나 번역이 실패한 파일은 번역 없이 저장할 수 있다.
- 왼쪽 열에서 **폴더**를 만들고(⇧⌘N) 레슨을 끌어다 놓아 정리한다. 여러 레슨을 골라 한꺼번에 옮기거나 내보낼 수 있고, 폴더를 지워도 안의 레슨은 ‘폴더 없음’으로 남는다.
- 레슨을 연 뒤에도 툴바의 **다시 번역**으로 Apple이나 Claude 번역을 다시 할 수 있다.
- 키보드는 웹 플레이어와 같다(Space, ←/→, T, R). 문장 목록은 오른쪽에 열고 닫는다.
- **아이폰용으로 내보내기**(⌘E)로 `.lrlesson`을 만들어 아이폰 앱으로 옮길 수 있고, PC·아이폰 레슨 파일도 가져올 수 있다. 기존 맥 앱에서 처리한 레슨은 **파일 → 이전 맥 앱 레슨 가져오기**로 옮긴다.
- Whisper·Claude는 기존 `pipeline.py`를 앱 안에 helper(`lcr-engine`)로 넣어 그대로 쓴다. Whisper 모델은 설정이나 새 레슨 창에서 한 번 내려받으며, 기존 맥 앱이 받은 모델이 있으면 그대로 쓴다.

```bash
bash scripts/build_mac.sh   # dist/macos/LC Repeater.app 과 zip
```

빌드에는 Xcode 26.4 이상(macOS SDK 26.4+)과 Python 3.9 이상이 필요하다. 서명하지 않은(ad-hoc) 앱이라 처음 열 때 막히면 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누른다. 구조와 개발 방법은 [네이티브 맥 앱 안내](docs/macos-native.md)에 정리했다.

## 기존 맥 앱으로 쓰기 (웹 화면, macOS 13+)

macOS 26보다 오래된 맥에서는 아래 Python·웹 화면 앱을 쓴다.


```bash
./build_app.sh
```

- `dist/LC Repeater.app`(약 31MB)이 만들어진다. 응용 프로그램 폴더로 옮겨 두고 더블클릭해서 쓴다.
- 처음 열면 음성 인식 모델(547MB)을 내려받는 화면이 나온다. 중간에 끊겨도 받은 데까지 이어서 받는다.
- 음원·처리 결과·모델·로그는 `~/Library/Application Support/LC Repeater/`에 저장된다.
- 번역은 `claude -p`로 한다. Claude Code를 설치하고 터미널에서 `claude`를 실행해 `/login` 해 두어야 한다. 로그인 전에도 문장 반복은 쓸 수 있고, 로그인 뒤 화면의 **번역 다시 하기**를 누르면 된다.
- Apple Silicon 맥, macOS 13 이상에서 돌아간다.
- 빌드에는 Xcode 명령줄 도구와 Python 3.9 이상(Homebrew)이 필요하다. 빌드 도구(PyInstaller, pywebview, cmake)는 `.venv`에만 설치되고, whisper.cpp v1.9.5를 받아 다른 라이브러리에 기대지 않는 실행 파일로 빌드해 앱에 넣는다.
- 서명하지 않은 앱이라 다른 맥에 파일로 옮기면 "확인되지 않은 개발자" 경고가 뜬다. 우클릭 → 열기로 열 수 있다.

## 브라우저로 쓰기 (개발용)

```bash
./setup.sh          # 처음 한 번: Homebrew whisper-cpp 설치, models/에 모델 받기
python3 server.py   # http://localhost:8765
```

- 데이터는 프로젝트의 `data/`에 저장된다. 서버 코드는 Python 3.7 이상 표준 라이브러리만 쓴다.
- 같은 와이파이의 휴대폰에서 쓰려면 `python3 server.py --lan`으로 띄우고 출력된 주소로 접속한다.

명령줄로만 처리할 수도 있다.

```bash
python3 pipeline.py 파일.mp3            # 처리 후 문장 목록 출력
python3 pipeline.py --lang ja 파일.mp3  # 일본어 음원
python3 pipeline.py --retranslate <id>  # 번역만 다시
python3 pipeline.py --resegment <id>    # 받아쓰기는 그대로 두고 문장 나누기와 번역을 다시
```

## 플레이어

| 조작 | 키 |
|---|---|
| 재생 / 정지 | Space |
| 이전 / 다음 문장 | ← / → |
| 원문 공개 → 한국어 → 원문 가리기 | T 또는 카드 누르기 |
| 처음부터 다시 | R |

- 반복 횟수(1~100회, 무한), 반복 사이 쉼(문장 길이만큼 쉬는 섀도잉 모드 포함), 속도(0.7~1.3×, 음 높이 유지), 다 들은 뒤 멈추기/다음 문장으로를 고를 수 있다.
- "시험 안내 문장 건너뛰기"를 켜면 문항 번호, 파트 설명 같은 문장을 목록에서 뺀다.
- 문장 앞뒤가 잘리거나 다음 문장이 섞이면 **구간 조절**로 0.1초씩 고친다. 고친 값은 저장된다.

## 처리 방식

1. 맥은 내장 `afconvert`, Windows는 함께 넣은 FFmpeg로 재생용 `master.wav`(32kHz 모노)와 인식용 16kHz wav를 만든다.
2. whisper.cpp로 받아쓴다. 앞 문장 문맥을 끊어(`-mc 0`) 보기 기호(A. B. C.)가 대화 문장에 잘못 붙는 것을 막고, 토큰별 시각(DTW)을 함께 받는다.
3. 문장부호와 쉼으로 문장을 나눈다. Whisper 시각은 0.1~0.6초씩 흔들려서, 문장 경계는 무음 구간(10ms 단위로 파일 평균보다 16dB 이상 조용한 곳) 안으로 옮기고 앞 0.12초, 뒤 0.2초의 여유를 둔다.
   - Whisper가 가끔 한 구간을 문장부호 없이 받아쓴다. 그런 덩어리는 0.33초 이상 쉬는 곳마다 자른다(문장 끝 쉼은 대개 이보다 길고 쉼표 자리는 짧다). 문장부호가 있어도 10초가 넘으면 가장 긴 쉼에서 자른다.
   - 일본어는 띄어쓰기가 없어서 토큰을 그대로 이어 붙이고, `。？！`로 문장을 끝내며, 길이 기준을 단어 수 대신 글자 수로 센다. whisper.cpp가 한 글자를 여러 토큰으로 쪼개 UTF-8이 깨진 경우 토큰을 합쳐 되살린다.
   - "Yes.", "Sure." 같은 한 단어 문장은 0.8초 미만으로 쉬고 이어지면 다음 문장에 붙인다.
   - 문장부호와 대문자는 번역 단계에서 Claude가 바로잡는다.
4. 문장 목록을 40개씩 묶어 `claude -p`로 번역한다. 같은 호출에서 명백한 인식 오류 교정과 시험 안내 문장 표시도 한다.
5. 재생할 때 서버가 `master.wav`에서 해당 구간만 잘라 WAV로 보낸다. 플레이어는 그 짧은 파일을 처음부터 끝까지 재생하므로 구간이 정확하다.

환경 변수로 바꿀 수 있는 것: `WHISPER_MODEL`(모델 경로), `LCR_DATA_DIR`(데이터 폴더), `LCR_SUPPORT_DIR`(앱의 데이터·모델 폴더), `LCR_MODEL_URL`(모델 내려받을 주소), `CLAUDE_MODEL`(기본 `sonnet`), `PORT`.

## 데이터

레슨마다 `data/<레슨 id>/`에 원본 음원, `master.wav`, `whisper.json`, `lesson.json`(문장·시각·번역)이 저장된다.

교재 음원과 스크립트는 저작권물이라 저장소에 올리지 않는다. `data/`, 음원 파일, 모델, 빌드 결과물은 `.gitignore`로 제외한다.
